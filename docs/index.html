Error Bars for LLM Evals

Evaluate a model on N questions with K runs (seeds) per question, report a “95%” interval — and the interval covers the true accuracy far less than 95% of the time, if it is the pooled interval everyone reaches for. Every number on this page comes from 6,000 real GSM8K runs (3 models × 400 questions × 5 seeds). Pick a design and see which intervals hold up.

Why questions beat seeds

An accuracy estimate varies for two reasons: questions differ in difficulty (between-question variance, σ²q), and the same question flips between runs (within-question variance, σ²w). The variance of the estimate at design (N, K) is σ²q/N + σ²w/(N·K). Extra seeds only shrink the second term; extra questions shrink both. For these models the first term dominates, so repeats are a poor buy:

Clustering uncertainty by question is not this project's idea: it is the recommendation of Miller (2024), “Adding Error Bars to Evals: A Statistical Approach to Language Model Evaluations” (arXiv:2411.00640), and this project follows it. What is added here is the empirical coverage check on real runs, the Bayesian comparison, the budget guidance, and this playground.
